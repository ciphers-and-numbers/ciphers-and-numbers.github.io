러닝페어 발표 파일

인터넷이 없어도 열리는 발표 파일입니다. 슬라이드 21장과 학생 웹앱 세 개(10608, 10211, 10203)가 파일 하나에 들어 있습니다.

⬇ 발표 파일 다운로드 ▶ 지금 바로 열기

1. 행사 전에 (인터넷 되는 곳에서)

  1. 갤럭시 탭에서 이 페이지를 열고 발표 파일 다운로드를 누릅니다.
  2. 비행기 모드를 켜고 아래 2번대로 한 번 열어 처음부터 끝까지 넘겨 봅니다.

2. 발표할 때 (인터넷 없이)

  1. 내 파일 앱 → 다운로드 폴더 → ciphers-learning-fair.html을 누르고 Chrome 또는 삼성 인터넷으로 엽니다.
  2. 아래 막대의 ⤢ 전체 화면을 누릅니다.
  3. 다음 → 버튼을 누르거나 화면을 옆으로 밀어서 넘깁니다.
  4. 20번 장에서 내 암호 카드를 누르면 웹앱이 열립니다. 설명이 끝나면 맨 위 ← 발표로 돌아가기를 누릅니다.
