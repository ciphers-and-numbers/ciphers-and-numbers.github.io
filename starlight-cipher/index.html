10125 학생은 한글 자음은 수로, 모음은 별·하트·세모 같은 기호로 바꾸는 암호를 만들었어요.

규칙을 숨겼을 때 AI는 풀지 못했어요. 규칙을 알려 주자 풀기는 했는데, AI가 수를 엉뚱한 곳에서 끊어 읽는 일이 생겼어요. 10125 학생은 이것을 보고 "기호가 여러 뜻으로 읽힐 수 있다"는 약점을 찾아냈어요.

자음은 ㄱ = 1, ㄴ = 2, …, ㅎ = 14로 번호를 붙여요. 이 웹앱에서는 기본 자음 14개와 기본 모음 10개로 된 글자만 써요. (쌍자음과 ㅐ, ㅔ 같은 모음은 쓰지 않아요)

"별빛 암호"는 10125 학생이 붙인 이름이에요. 어떤 모음에 어떤 기호를 썼는지는 기록에 다 남아 있지 않아서, 기호표는 이 웹앱에서 정했어요.
