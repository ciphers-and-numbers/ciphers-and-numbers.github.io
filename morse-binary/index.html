활동 4. 짝 활동: 모스-이진 비밀 대화 13분

짧은 영어 단어(3~5글자)를 하나 정해 모스 부호로 바꾸고, • = 0, − = 1로 바꿔 짝에게 보내요. (글자 사이는 / )

짝의 신호를 거꾸로 풀어 맞혀 봐요.
