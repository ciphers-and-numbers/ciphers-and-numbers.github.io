10203 학생의 TPTP 암호

10203 학생은 한글 자음과 모음을 원소 기호로 바꿨어요. 규칙을 숨겼을 때 AI는 풀지 못했지만, 대응 규칙을 설명하자 풀었어요. 학생도 AI의 답장을 해독했어요.

암호 해독 대결에서는 낱말 사이에 원소 기호를 끼워 넣는 ‘2TPTP 암호’로 바꿨어요.

웹앱을 만들며 정한 것

활동 요약에 남은 ㄱ·ㄴ·ㅡ의 대응을 살리고, 나머지 기본 자음과 모음에는 서로 겹치지 않는 원소 기호를 붙였어요. 원자 번호나 원소의 성질은 사용할 필요가 없어요.

원소 기호는 첫 글자를 대문자로, 두 글자 기호는 둘째 글자를 소문자로 쓰는 것이 약속이에요. 이 웹앱의 채점에서는 대소문자 차이를 허용해요.

기호 사이는 띄어 쓰고, 음절 사이는 /, 낱말 사이는 |로 나눠요. 2TPTP에서는 낱말과 낱말 사이에 기호 하나를 | 기호 | 꼴로 넣어요. 끼워 넣을 기호는 연습할 때마다 고를 수 있어요.

기본 자음·모음으로 된 한글을 사용해요. 겹받침과 ㅐ·ㅔ처럼 표에 없는 모음이 든 낱말은 다른 낱말로 바꿔 주세요.

학번을 쓰고 시작하기

  1. 자모와 원소 기호 대응시키기
  2. 한글 암호 만들고 풀기
  3. 기호와 음절의 경계 찾기
  4. 사이에 끼운 기호 가려내기
  5. 나만의 2TPTP로 짝과 주고받기

도전을 마칠 때마다 별이 하나씩 채워져요.

자모 하나에 원소 기호 하나

C, O, Co는 서로 다른 원소 기호예요. 두 글자 기호인 Co는 C와 O를 띄어 쓴 것과 구분해요.

기호를 찾아 쓰기

실제 원소 기호에서는 첫 글자를 대문자로, 두 번째 글자가 있으면 소문자로 써요.

자모로 나누어 암호 만들기

한 음절은 첫 자음과 모음, 받침이 있으면 받침까지 차례로 바꿔요. 예를 들어 고를 ㄱ과 ㅗ로 나누면 가 돼요.

기호 사이는 띄고, 음절 사이는 /로 나누세요.

암호를 다시 한글로

빗금 앞뒤를 따로 읽고, 각 음절의 기호를 표에서 자모로 되돌리세요.

어디서 끊을까

하나의 원소 기호는 영문자 한 글자 또는 두 글자예요. 원소 기호 두 개 또는 세 개가 한 음절을 만들어요.

/는 음절을, 띄어쓰기는 원소 기호를 나눠요.

기호 수와 음절 수를 비교하기

기호를 나누는 약속과 음절을 나누는 약속은 역할이 달라요. 예를 들어 H는 영문자 하나, Au는 둘이지만 각각 원소 기호 하나예요.

2TPTP 해독하기

10203 학생은 해독 대결에서 낱말 사이에 원소 기호를 끼워 넣었어요. 이 웹앱에서는 낱말 사이에 기호 하나가 든 묶음을 하나씩 넣습니다.

낱말만 남겨 읽기

끼운 묶음을 건너뛰고 남은 두 낱말을 자모표로 풀어 보세요.

한글 음절을 만들려면 자음과 모음에 해당하는 기호가 필요해요. 기호가 하나뿐인 묶음은 이 방식으로 만든 한글 낱말이 될 수 없어요.

나만의 2TPTP 만들기

표에 있는 자모로 된 한글 두 낱말을 쓰세요. 낱말마다 1~4음절이에요. 사이에 끼울 원소 기호를 하나 골라 암호문을 완성하세요.

받은 암호 되돌리기

복사한 암호문은 받은 암호문 칸에 붙여 넣으면 돼요. 친구에게 원래 낱말은 보여 주지 마세요.
