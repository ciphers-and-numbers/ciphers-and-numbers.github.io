알파벳 번호표
A부터 Z까지 0부터 25까지 번호를 붙입니다.
약속

원래 글자 번호 = P
암호 글자 번호 = C
미는 칸 수(열쇠) = k

암호화: C = P + k
  (25를 넘으면 26 빼기)

복호화: P = C − k
  (0보다 작으면 26 더하기)
암호 원판
바깥 원 = 원래 글자, 안쪽 원 = 내가 쓴 암호 글자
활동 1. 나만의 암호 원판 완성하기 10분
  1. 나만의 열쇠 k를 정해요. (1~25 중 하나)
  2. A 안쪽 칸에 A에서 k칸 뒤의 글자를 써요. 예) k = 3이면 A 안쪽에 D
  3. 시계 방향으로 한 칸씩 이어 써요. Z 다음은 다시 A!
  4. 26칸이 모두 다른 글자인지 원판에서 확인해요.
원판으로 확인하기
열쇠가 3일 때 Y의 암호 글자는?
24 + 3 = 27 → 27 − 26 = → 암호 글자

정수의 뺄셈으로 복호화합니다.

예) Z: 25 − 7 = 18 → S
