약속

원래 글자 번호 = P
암호 글자 번호 = C
미는 칸 수(열쇠) = k

암호화: C = P + k
  (25를 넘으면 26 빼기)

복호화: P = C − k
  (0보다 작으면 26 더하기)
알파벳은 원처럼 돌아요.
Z(25)에서 오른쪽으로 3칸 → 25 + 3 = 28 → 28 − 26 = 2 → C
26을 빼는 것은 26으로 나눈 나머지를 구하는 것과 같아요. (28 ÷ 26 = 1 … 나머지 2)
