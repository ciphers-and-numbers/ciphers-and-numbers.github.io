10406 학생의 "일차식 암호"
「나만의 암호 설계」 수업에서 만든 암호예요.

10406 학생은 알파벳에 순서대로 번호를 붙였어요. A = 1, B = 2, …, Z = 26

그리고 번호 x를 어떤 일차식에 넣어 나온 수를 암호로 보냈어요. 예를 들어 S(19)를 39로 바꿨어요.

시저 암호 수업에서는 A = 0부터 셌지만, 10406 학생은 A = 1부터 셌어요. 암호를 만든 사람의 약속을 따라야 해요.

10406 학생이 남긴 성찰: "계산이 편리하지만 단순 역산으로 쉽게 풀린다는 약점이 있다." 정말 그런지 직접 확인해 봅시다.
